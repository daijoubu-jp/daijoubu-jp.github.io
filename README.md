# 🌸 KanjiThai - พจนานุกรมและคลังการเรียนรู้คันจิไทย-ญี่ปุ่น

> เว็บไซต์พจนานุกรมคันจิภาษาไทยที่ครบถ้วนและทันสมัยที่สุด รวมคันจิโจโย (常用漢字) 2,136 ตัว และคันจิข้อสอบคันเค็น (漢字検定) ครอบคลุมระดับ JLPT N5 ถึง N1 พร้อมระบบจำลองลำดับขีด คำศัพท์ สำนวนอนิเมะ และเครื่องมือสร้างใบงานคัดลายมือ A4

---

## ✨ ฟีเจอร์หลัก (Key Features)

- 🔍 **ค้นหาคันจิฉับไว (Instant Search & Filter)**:
  - ค้นหาได้ด้วยภาษาไทย, ญี่ปุ่น (Kanji / Hiragana / Katakana / Romaji) หรือความหมายภาษาอังกฤษ
  - ระบบตัวกรองละเอียด: ขอบเขตคันจิ (โจโย / นอกโจโย), ระดับ JLPT (N5–N1), ระดับคันเค็น (10級–1級), ระดับชั้นเรียนประถม-มัธยมญี่ปุ่น, จำนวนขีด และหมวดอักษร (Radicals)
- ✍️ **แอนิเมชันแสดงลำดับการเขียน (Stroke Order Animator)**:
  - แอนิเมชันการลากเส้นทีละขีดแบบอินเทอร์แอคทีฟ (เล่นซ้ำ, หยุดชั่วคราว, ก้าวหน้า-ถอยหลัง)
  - ปรับความเร็วการลากเส้น (Speed: 1.25s–3s) และการหน่วงเวลาระหว่างขีด (Pause: 1s–3s)
  - เลือกเส้นไกด์ฝึกเขียน: ✕ ไม่มีเส้นไกด์, 田 เส้นประ 4 ช่อง (十字), 米 เส้นประ 8 ทิศ (米字)
  - โมดอลขยายดูลำดับขีดขนาดใหญ่
- 🏛️ **ความเป็นมาและที่มาของคันจิ (Origin & Etymology - 成り立ち)**:
  - อธิบายกำเนิดคันจิ 4 ประเภทหลัก: อักษรภาพ (象形), สัญลักษณ์เชิงนามธรรม (指事), ผสมความหมาย (会意), ผสมรูปและเสียง (形声)
  - แสดงตัวอักษรส่วนประกอบที่สามารถคลิกเพื่อเชื่อมโยงไปยังคันจิที่เกี่ยวข้องได้ทันที
- 📚 **คลังคำศัพท์และสำนวนมังงะ/อนิเมะ (Vocabulary & Jukugo Hub)**:
  - คำศัพท์และสำนวนคันจิหมวดหมู่หลากหลาย ทั้งคำศัพท์ทั่วไปในชีวิตประจำวัน และคำศัพท์/ท่าไม้ตายยอดนิยมจากมังงะ & ออนิเมะ
  - ระบบเปิด-ปิดเสียงอ่านฟุริงะนะ (Furigana Toggle)
  - ระบบอ่านออกเสียงคำศัพท์ภาษาญี่ปุ่น (Web Speech Audio)
  - ปุ่มคัดลอกคำศัพท์เพื่อนำไปสร้างการ์ดคำศัพท์สำหรับท่องจำ (Anki / Flashcards)
- 📝 **ระบบสร้างใบงานแบบฝึกหัดคัดคันจิ (A4 Worksheet Generator)**:
  - กำหนดตัวอักษรคันจิที่ต้องการคัดได้เองอิสระ หรือเลือกชุดสำเร็จรูปตามระดับชั้น
  - เลือกลายเส้นไกด์ (田 / 米 / ▢) และจำนวนช่องตัวอักษรจางสำหรับฝึกคัดตามรอย
  - สั่งพิมพ์ลงกระดาษขนาดมาตรฐาน A4 หรือบันทึกเป็นไฟล์ PDF ได้ในคลิกเดียว
- 🎨 **ธีมสไตล์ญี่ปุ่น 6 ฤดูกาล (6 Japan-Inspired Themes)**:
  - 🌸 ฤดูใบไม้ผลิ (Haru / Sakura)
  - 🏮 ฤดูร้อน (Natsu / Summer Matsuri)
  - 🍁 ฤดูใบไม้ร่วง (Aki / Momiji)
  - ❄️ ฤดูหนาว (Fuyu / Snow)
  - 🎌 อนิเมะนีออน (Anime / Cyberpunk)
  - 🎨 ภาพพิมพ์อุกิโยะเอะ (Ukiyo-e / Classic Woodblock)
  - รองรับโหมดสว่าง/โหมดมืด (Light/Dark Mode) สลับอัตโนมัติ
- 📱 **รองรับการใช้งานบนทุกอุปกรณ์ (Fully Responsive)**:
  - ออกแบบตามหลัก Mobile-First รองรับสมาร์ตโฟน (360px–430px), แท็บเล็ต และเดสก์ท็อป
  - เมนูหลักบนมือถือระบบ Accordion พับเก็บได้ ป้องกันการเลื่อนจอเกินจำเป็น

## 🛠️ สถาปัตยกรรมและเทคโนโลยี (Tech Stack)

- **Frontend**: HTML5 Semantic, Modern CSS3 (CSS Custom Properties, Grid, Flexbox), Vanilla JavaScript (ES Modules)
- **Zero Framework / Zero Build Step**: สามารถเปิดใช้งานหรือโฮสต์ได้ทันทีโดยไม่ต้องผ่านกระบวนการ build/compile
- **Fonts**: Noto Sans JP, Noto Serif JP, Noto Sans Thai Looped
- **Data Source**:
  - [KANJIDIC2](http://www.edrdg.org/kanjidic/kanjidic2.xml.gz) & [KanjiVG](https://kanjivg.tagaini.net/)
  - กระทรวงศึกษาธิการและวัฒนธรรมญี่ปุ่น (MEXT / 文化庁 Bunkachō 2010 Joyo Table)
  - สมาคมทดสอบความถนัดคันจิแห่งประเทศญี่ปุ่น (日本漢字能力検定協会)

## 🚀 การเผยแพร่และการติดตั้ง (Deployment)

### วิธีการเปิดใช้งานผ่าน GitHub Pages

1. เข้าไปที่ **Settings** ของ Repository บน GitHub
2. ไปที่เมนู **Pages** (แถบเมนูด้านซ้าย)
3. ภายใต้หัวข้อ **Build and deployment > Source**:
   - เลือก **Deploy from a branch**
   - Branch: เลือก `main` / โฟลเดอร์ `/(root)`
4. กด **Save**
5. รอระบบของ GitHub ประมวลผลประมาณ 1–2 นาที จะได้รับ URL สำหรับเข้าชมเว็บไซต์ (เช่น `https://<username>.github.io/<repo-name>/`)
