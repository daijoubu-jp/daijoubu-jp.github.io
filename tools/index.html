ศูนย์รวมเครื่องมือช่วยเรียนคันจิ
(Kanji Learning Tools • 漢字学習ツール)

เครื่องมือและยูทิลิตี้เพื่อสนับสนุนการเรียนการสอนภาษาญี่ปุ่น ทั้งใบงานฝึกคัดลายมือ เครื่องมือนับขีด และเครื่องมือช่วยแปลงฟุริงะนะ

🖨️
ตัวสร้างใบงานคัดลายมือคันจิ (Worksheet Maker)
