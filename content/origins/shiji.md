## 一

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

มาจากขีดเส้นแนวนอนหนึ่งเส้นเพื่อเป็นสัญลักษณ์แทนจำนวนนับ 'หนึ่ง'

## 二

- type: 指事文字

## 四

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

ในอักษรโบราณเดิมเขียนเป็นขีดสี่เส้น ต่อมาเปลี่ยนเป็นรูปปากที่พ่นลมหายใจออกเป็นสี่สาย (呬) เพื่อไม่ให้สับสนกับเส้นขีดอื่นๆ หมายถึง 'สี่'

---

## 五

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

เดิมเป็นเครื่องหมายกากบาทกึ่งกลางระหว่างฟ้าและดิน สื่อถึงธาตุทั้งห้า (ดิน น้ำ ไฟ ลม ทอง) หมายถึง 'ห้า'

---

## 上

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

ในอักษรโบราณ ลากเส้นฐานแนวนอนหนึ่งเส้น และแต้มจุดหรือขีดสั้นไว้เหนือเส้น เพื่อเป็นสัญลักษณ์แสดงตำแหน่ง 'ด้านบน'

## 本

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

ต่อยอดจากคันจิ 木 (ต้นไม้) โดยเติมขีดแนวนอนสั้นๆ ไว้ที่บริเวณโคนราก เพื่อชี้ระบุถึง 'รากไม้ / โคนต้น' แล้วขยายความหมายสู่ 'รากฐาน / เล่มหนังสือ'

### Components

- **木** (สัญลักษณ์รูปทรง): ต้นไม้
- **一** (เครื่องหมายชี้ระบุ): ตำแหน่งโคนราก

---

## 末

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

ต่อยอดจากคันจิ 木 (ต้นไม้) โดยเติมขีดแนวนอนยาวที่บริเวณยอดกิ่งไม้ด้านบน เพื่อชี้ระบุถึง 'ปลายยอดไม้' แล้วขยายความหมายสู่ 'ปลายทาง / ท้ายสุด'

### Components

- **木** (สัญลักษณ์รูปทรง): ต้นไม้
- **一** (เครื่องหมายชี้ระบุ): ตำแหน่งปลายยอด

## 言

- type: 指事文字
- type_th: อักษรสัญลักษณ์เชิงนามธรรม

### Description

ด้านล่าง 口 คือปาก และมีเส้นขีดแต้มเหนือปากขึ้นไปหลายชั้นแทนเสียงพูดที่เปล่งพุ่งออกจากช่องปาก หมายถึง 'คำพูด / ภาษา / วาจา'
