## 金

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ด้านบน 𠓛 มาจากหลังคาหรือฝาครอบ ด้านล่าง 土 แสดงดิน และมีจุดเล็กๆ สองจุดแสดงเศษแร่โลหะมีค่าที่ฝังตัวอยู่ใต้ผืนดิน โดยมี 今 ทำหน้าที่เป็นส่วนช่วยกำหนดเสียงอ่านดั้งเดิม หมายถึง 'ทองคำ / โลหะ / เงินตรา'

---

## 花

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนบน 艹 (艸部: หญ้า/พืช) เป็นส่วนบ่งบอกความหมาย (意符) ว่าเกี่ยวกับพฤกษา ส่วนล่าง 化 ทำหน้าที่เป็นส่วนบอกเสียงอ่าน (音符: คา) และสื่อถึงการเปลี่ยนแปลงรูปทรง หมายถึง 'ดอกไม้ที่ผลิดอกตูมสู่บานสะพรั่ง'

---

## 空

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนบน 穴 (โพรง/ถ้ำ) เป็นส่วนบ่งชี้ความหมาย (意符) สื่อถึงความเวิ้งว้างโปร่งโล่ง ส่วนล่าง 工 ทำหน้าที่เป็นส่วนบอกเสียงอ่าน (音符: โค) หมายถึง 'ท้องฟ้าอันเวิ้งว้าง / ความว่างเปล่า'

---

## 海

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนซ้าย 氵 (水: น้ำ) บ่งบอกความหมาย (意符) ว่าเกี่ยวกับผืนน้ำอันกว้างใหญ่ ส่วนขวา 毎 ทำหน้าที่เป็นส่วนบอกเสียงอ่าน (音符: ไค) และสื่อถึงความมืดมิดลึกล้ำ หมายถึง 'ทะเล / มหาสมุทร'

---

## 風

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

กรอบนอก 几 สื่อถึงสายลมที่พัดกระพือโอบล้อม ส่วนด้านใน 虫 (แมลง) ตามความเชื่อจีนโบราณว่าสายลมในฤดูใบไม้ผลิพัดพาแมลงตัวเล็กๆ ให้ฟื้นตื่นขึ้น หมายถึง 'สายลม / บรรยากาศ'

### Components

- **虫** (音符・意符): สิ่งมีชีวิตที่ตื่นเพราะลม

---

## 語

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนซ้าย 言 (คำพูด/วาจา) เป็นส่วนบ่งบอกความหมาย (意符) ส่วนขวา 吾 (ข้าพเจ้า/ตนเอง) ทำหน้าที่เป็นส่วนบอกเสียงอ่าน (音符: โก) หมายถึง 'การเปล่งถ้อยคำเพื่อบอกเล่าความคิดของตนเอง ➔ ภาษา / ถ้อยคำ'

## 字

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนบน 宀 (หลังคาบ้าน) รวมกับ 子 (เด็ก/ทารก) ดั้งเดิมหมายถึงการให้กำเนิดและเลี้ยงดูบุตรในบ้าน ต่อมาขยายความหมายสู่อักษรที่แตกแขนงเกิดคำใหม่อย่างไม่สิ้นสุด หมายถึง 'ตัวอักษร / ตัวหนังสือ'

### Components

- **子** (音符・意符): ทารก / การเพิ่มพูน

---

## 漢

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนซ้าย 氵 (น้ำ) บ่งบอกความหมายแม่น้ำฮั่น (漢水) ส่วนขวา 𦰌 (かん) ทำหน้าที่เป็นส่วนบอกเสียงอ่าน ต่อมากลายเป็นชื่อราชวงศ์ฮั่นและใช้เรียกชนชาติและตัวอักษรจีน หมายถึง 'ราชวงศ์ฮั่น / ตัวอักษรคันจิ / ลูกผู้ชาย'

---

## 愛

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

เกิดจาก 旡 (หันหลังมอง) + 心 (หัวใจ) + 夊 (การก้าวเท้าเดินช้าๆ) สื่อภาพคนที่กำลังก้าวเท้าเดินจากไปแต่ในหัวใจยังคงผูกพันอาลัยอาวรณ์จนต้องเหลียวหลังกลับมามองซ้ำแล้วซ้ำเล่า หมายถึง 'ความรัก / ความเสน่หาผูกพัน'

---

## 星

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนบน 日 (ดวงอาทิตย์/แสงสว่างบนฟ้า) บ่งบอกความหมายดวงดาวระยิบระยับ ส่วนล่าง 生 ทำหน้าที่เป็นส่วนบอกเสียงอ่าน (音符: เซย์) สื่อถึงแสงดาวที่กำเนิดระยิบระยับบนฟ้าคราม หมายถึง 'ดวงดาว'

---

## 桜

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ในรูปโบราณ 櫻 มีส่วนซ้าย 木 (ต้นไม้) เป็นส่วนบอกความหมาย และส่วนขวา 嬰 สื่อถึงสร้อยคอร้อยลูกปัดเปล่งประกาย สื่อถึงต้นไม้ที่มีดอกไม้เล็กๆ ผลิบานห้อยระย้าดุจสร้อยคอเพชรพลอย หมายถึง 'ดอกซากุระ'

---

## 聞

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนนอก 門 (ซุ้มประตู) ทำหน้าที่เป็นส่วนบอกเสียงอ่าน (ブン) ส่วนด้านใน 耳 (ใบหู) เป็นส่วนบ่งบอกความหมาย สื่อถึงการแนบหูฟังที่ประตูเพื่อรับฟังข่าวสาร หมายถึง 'ได้ยิน / ฟัง / ไต่ถาม'

## 読

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนซ้าย 言 (คำพูด/วาจา) บ่งบอกความหมาย ส่วนขวา 売 (เดิมคือ 𧸇: โทคุ) ทำหน้าที่เป็นส่วนบอกเสียงอ่าน สื่อถึงการเปล่งเสียงอ่านข้อความออกมาเป็นถ้อยคำ หมายถึง 'อ่าน'

## 飲

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

ส่วนซ้าย 飠 (食: อาหาร) บ่งบอกความหมาย ส่วนขวา 欠 (ภาพคนอ้าปากกว้างและโน้มศีรษะลง) สื่อถึงการอ้าปากดื่มกลืนน้ำเข้าสู่ลำคอ หมายถึง 'ดื่ม'

## 道

- type: 形声文字
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วน 辶 (辵: การก้าวเดินบนถนน) เป็นส่วนบอกความหมาย ส่วน 首 (ศีรษะ/มุ่งหน้า) ทำหน้าที่บอกเสียงอ่านและทิศทาง สื่อถึงการก้าวเดินมุ่งหน้าไปตามทาง หมายถึง 'ถนน / เส้นทาง / วิถีทางคุณธรรม'

### Components

- **首** (音符・意符): มุ่งหน้า / เสียง トウ (dō)

## 青

- type: 会意・形声
- type_th: อักษรประสมเสียงและความหมาย

### Description

ส่วนบน 生 (การแตกยอดอ่อนของพืช) รวมกับ 丹 (แร่ธาตุธรรมชาติ) สื่อถึงสีเขียวมรกตสดของยอดไม้ที่เพิ่งผลิใบ หรือสีครามของท้องฟ้าสดใส หมายถึง 'สีฟ้า / สีเขียวสด / ความเยาว์วัย'

### Components

- **生** (音符・意符): ยอดไม้งอกงาม
