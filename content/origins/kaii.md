# 会意文字 - อักษรผสมความหมาย

## 男

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

เกิดจากการประสมกันของ 田 (ทุ่งนา) + 力 (คันไถหรือกล้ามแขนที่ออกแรง) สื่อความหมายถึง 'ผู้ที่ใช้พละกำลังออกแรงทำงานในท้องนา' หมายถึง 'ผู้ชาย'

---

## 休

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

เกิดจากการนำ 亻 (人: มนุษย์) มารวมกับ 木 (ต้นไม้) สื่อภาพคนที่เหน็ดเหนื่อยจากการตรากตรำทำงานแล้วเดินมาพิงร่มเงาของต้นไม้ใหญ่เพื่อคลายความเหนื่อยล้า หมายถึง 'หยุดพัก / พักผ่อน'

---

## 森

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

นำ 木 (ต้นไม้) สามต้นมาซ้อนเรียงกัน บ่งบอกถึงพื้นที่ที่มีต้นไม้นานาพันธุ์ขึ้นอยู่อย่างหนาแน่นจนบดบังแสงแดด หมายถึง 'ป่าทึบ / ป่าดงดิบ'

---

## 林

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

นำ 木 (ต้นไม้) สองต้นมาวางเคียงคู่กัน หมายถึง พื้นที่ที่มีต้นไม้ขึ้นรวมกันเป็นกลุ่ม 'ป่าละเมาะ / แนวป่า'

---

## 明

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

รวมสองแหล่งกำเนิดแสงที่สว่างที่สุดบนท้องฟ้าระหว่าง 日 (ดวงอาทิตย์ยามกลางวัน) และ 月 (ดวงจันทร์ยามค่ำคืน) บ่งบอกถึง 'ความสว่างไสว / ชัดเจน / แจ่มแจ้ง'

---

## 夢

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

ประกอบด้วย 艹 (ขนตายาวสลัว) + 目 (ดวงตาที่พร่ามัว) + 冖 (ความมืดมิด) + 夕 (ยามค่ำคืน) สื่อถึง 'ภาพลางเลือนที่มองเห็นในยามค่ำคืนขณะหลับใหล' หมายถึง 'ความฝัน'

---

## 見

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

เกิดจาก 目 (ดวงตาขนาดใหญ่เด่นชัด) ตั้งอยู่บน 儿 (ขามนุษย์ในท่ายืน) สื่อถึง 'คนที่กำลังเบิกตากว้างมองดูสิ่งต่างๆ' หมายถึง 'มองเห็น / ประจักษ์'

---

## 書

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

ส่วนบน 聿 สื่อถึงมือที่กำลังจับด้ามพู่กันเขียนหนังสือ ส่วนล่าง 日 (เดิมคือ 曰 หรือภาชนะรองหมึก) สื่อถึงการจารึกถ้อยคำลงบนแผ่นป้าย หมายถึง 'เขียน / หนังสือ / ลายลักษณ์อักษร'

---

## 食

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

ส่วนบน 亼 คือฝาปิดครอบภาชนะ ส่วนล่าง 皀 คือชามอาหารทรงสูงมีเชิงที่มีข้าวพูนอยู่ด้านใน สื่อถึง 'การรับประทานอาหารอันโอชะ'

---

## 信

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

เกิดจาก 人 (มนุษย์) + 言 (คำพูด) สื่อถึง 'คำพูดของมนุษย์ที่ยึดถือได้และไม่บิดเบือน' หมายถึง 'ความจริงใจ / ความเชื่อถือ / ศรัทธา'

---

## 鳴

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

เกิดจาก 口 (ปาก) + 鳥 (นก) สื่อภาพนกที่กำลังอ้าปากส่งเสียงร้องขับขาน หมายถึง 'ส่งเสียงร้อง (สัตว์) / ดังกังวาน'

---

## 炎

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

นำ 火 (ไฟ) สองดวงมาซ้อนทับกัน แสดงถึงเปลวเพลิงที่กำลังโหมกระหน่ำลุกโชติช่วงเป็นทวีคูณ หมายถึง 'เปลวไฟ / ร้อนแรง / อักเสบ'

---

## 岩

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

เกิดจาก 山 (ภูเขา) + 石 (ก้อนหิน) สื่อถึงก้อนหินมหึมาที่ตั้งตระหง่านอยู่บนยอดเขา หมายถึง 'หินผา / โขดหิน'

---

## 赤

- type: 会意文字
- type_th: อักษรประสมความหมาย

### Description

ส่วนบน 大 (ผู้ใหญ่) รวมกับส่วนล่าง 火 (เปลวไฟ) สื่อภาพเปลวไฟขนาดใหญ่ที่สว่างโร่ หมายถึง 'สีแดง / สีเพลิง'
