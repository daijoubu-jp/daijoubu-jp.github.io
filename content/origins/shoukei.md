## 日

- type: 象形文字
- type_th: อักษรภาพเลียนรูปทรง

### Description

มีที่มาจากภาพวาดดวงอาทิตย์กลมโตและมีจุดหรือเส้นขวางตรงกลางเพื่อแสดงความสว่างไสว ต่อมาในยุคอักษรทาสและอักษรบรรจงได้คลี่คลายสัณฐานเป็นทรงสี่เหลี่ยมเพื่อให้เขียนง่ายขึ้นด้วยพู่กัน หมายถึง 'ดวงอาทิตย์ / กลางวัน / พระอาทิตย์'

---

## 月

- type: 象形文字
- type_th: อักษรภาพเลียนรูปทรง

### Description

มาจากภาพวาดพระจันทร์เสี้ยวบนท้องฟ้าโบราณ เส้นขวางด้านในแสดงแสงเงาบนพื้นผิวดวงจันทร์ หมายถึง 'ดวงจันทร์ / เดือน'

---

## 木

- type: 象形文字
- type_th: อักษรภาพเลียนรูปทรง

### Description

มาจากภาพวาดต้นไม้ทั้งต้น โดยเส้นตั้งคือลำต้น เส้นขวางและเส้นปัดบนคือกิ่งก้านสาขา และเส้นปัดเฉียงซ้ายขวาล่างคือรากไม้ที่หยั่งลึกในดิน หมายถึง 'ต้นไม้ / ไม้'
